## 测试人员上下文

### 角色定位
测试人员是**第三方验证者**，负责：
- ✅ **不修改主程序代码**（src/目录下的所有文件）
- ✅ **仅通过HTTP API** 操作和验证系统行为
- ✅ **模拟真实用户场景**，验证系统功能完整性
- ✅ **输出测试文档**和需求文档

### 上下文隔离原则
```
每个测试必须使用独立的ouid（组织ID）和puid（人员ID）组合
确保测试数据之间完全隔离，不会相互影响

context = {ouid, puid} 表示 "person@organization" 上下文
例如：test_ouid="test_org", test_puid="test_user" 用于测试专用上下文
```

### 测试数据管理
| 类型 | 管理方式 | 清理策略 |
|------|---------|---------|
| 组织 | 创建测试专用组织 | 测试完成后删除 |
| 人员 | 仅在测试组织内创建 | 与组织一同清理 |
| 资源 | 关联到测试组织 | 随组织清理 |
| 交易 | 关联到测试组织 | 随组织清理 |

## 测试原则

### 1. 黑盒测试原则
```
禁止直接访问数据库或修改src/目录
所有数据操作必须通过HTTP API完成
```

### 2. 隔离性原则
```python
# 正确：每个测试使用独立的ouid+puid组合
test_ouid = "test_org_999"  # 测试专用组织业务标识
test_puid = "test_user_1001"  # 测试专用人员业务标识
client.post("/organizations", json={"ouid": test_ouid, ...})
client.post("/organizations/members", json={"ouid": test_ouid, "puid": test_puid, ...})

# 错误：使用生产环境的组织ID
client.post("/organizations", json={"id": 1, ...})  # ❌
```

### 3. 可重复性原则
```
测试必须可重复执行，不会因环境状态不同而失败
每次测试前准备干净的数据状态
```

### 4. 完整性原则
```
覆盖所有核心功能模块：
✓ 组织管理
✓ 人员管理  
✓ 资源管理
✓ 仓库管理
✓ 交易记录
✓ 参与方管理
```

## API测试框架

### 测试用例设计规范

"""
test_fire_newye_api.py
火烧新野战役 - API测试脚本

⚠️ 重要：测试用例需经项目经理审核通过后方可执行
"""

import pytest
from fastapi.testclient import TestClient
from src.app import app

client = TestClient(app)

# 测试专用组织ID（避免与生产数据冲突）
SHU_HAN_ORG_ID = 1001
CAO_WEI_ORG_ID = 1002

class TestFireNewyeBattle:
    """火烧新野战役测试套件"""
    
    def test_setup_shuhan_resources(self):
        """步骤1：蜀汉准备火攻物资"""
        # 创建物资
        resp = client.post("/resource", json={
            "ouid": SHU_HAN_ORG_ID,
            "name": "火箭",
        "resource_type": "physical",
        "unit": "支",
        "quantity": 5000,
        "warehouse": "武库A"
        })
        assert resp.status_code == 200
        
        # 存入仓库
        resp = client.post("/resource-warehouse", json={
            "resource_id": resp.json()["id"],
            "location_path": "武库A",
            "quantity": 5000,
            "unit": "支"
        })
        assert resp.status_code == 200
    
    def test_fire_attack(self):
        """步骤2：执行火攻（夜间用铜镜引火）"""
        # 蜀汉发射火箭
        resp = client.post("/resource-warehouse", json={
            "resource_id": 1,  # 火箭
            "location_path": "发射",
            "quantity": -100,  # 减少100支
            "unit": "支"
        })
        assert resp.status_code == 200
        
        # 曹魏用铜镜反射阳光引燃（夜间用火把）
        resp = client.post("/resource-warehouse", json={
            "resource_id": 2,  # 火把
            "location_path": "曹营",
            "quantity": -50,
            "unit": "支"
        })
        assert resp.status_code == 200
    
    def test_cao_wei_response(self):
        """步骤3：曹魏援军抵达"""
        # 曹魏调集援军
        resp = client.post("/transaction", json={
            "ouid": CAO_WEI_ORG_ID,
            "amount": 5000,
            "category": "军事调度",
            "description": "徐晃援军粮草"
        })
        assert resp.status_code == 200
    
    def test_shuhan_retreat(self):
        """步骤4：蜀汉成功撤退"""
        # 清理战场物资
        resp = client.post("/resource-warehouse", json={
            "resource_id": 1,
            "location_path": "撤退",
            "quantity": -4900,
            "unit": "支"
        })
        assert resp.status_code == 200
        
        # 验证剩余物资
        resp = client.get("/resource-warehouse/total", params={
            "resource_id": 1
        })
        assert resp.status_code == 200
        assert resp.json()["total_qty"] == 100  # 剩余100支火箭


if __name__ == "__main__":
    pytest.main([__file__, "-v"])
```
