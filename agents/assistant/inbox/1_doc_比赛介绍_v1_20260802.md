# 概述
加入由 AMD（Advanced Micro Devices, Inc.）主办的 AMD AI DevMaster 黑客松。本次黑客松聚焦前沿 AI 应用创意和高性能 AMD GPU 技术。选择你心仪的赛道！探索 AI 应用的无限可能，借助完全开源的 AMD ROCm 软件栈释放 AMD GPU 的全部计算潜力。让强大的 AMD Radeon GPU 成为你实现创意想法、运行模型的终极引擎！
本次黑客松包含三个赛道，涵盖 AI 创新应用开发的核心方向。无论你擅长将创意转化为实际应用，还是精于底层技术优化，这里都能找到属于你的理想舞台！

# 赛道二：私有 AI Agent 开发与本地部署
采用开源 AI Agent 开发套件，在 AMD Radeon GPU 和 ROCm 平台上完成全流程本地私有化部署，打造高度适配、可定制的专用 AI Agent。参赛者可自由定义应用场景，打破通用 AI 工具的功能局限，创造出具备场景化服务能力的智能体。
可用场景包括个人智能助手、办公自动化助手、行业专用服务 Agent、日常生活管理工具等。本赛道重点考察参赛者利用 AMD GPU 算力优化 Agent 推理速度、提升本地部署稳定性以及实现自定义迭代功能的能力，目标在于打造轻量化、高可用、私密化的 AI 智能服务终端。

# 规则
## 赛道二：私有 AI Agent 开发与本地部署
1. 任务描述
基于 AMD Radeon GPU 和 ROCm 平台，结合开源 AI Agent 开发框架，构建完全本地化部署、可定制且具备工具链调用能力的 AI Agent 系统。你的作品应面向特定应用场景，包括但不限于：
● 个人智能助手
● 办公自动化助手
● 行业专用服务 Agent
● 本地知识库问答助手
● 日程 / 文档 / 邮件处理助手
● 生活管理 AI Agent
● 其他自定义场景
● 作品应展示以下能力：在 AMD Radeon GPU 上本地部署
● 场景化任务执行
● 工具调用与工作流编排
● 本地运行环境下的操作稳定性与响应性能
2. 指定技术栈
（1）平台要求
● 必须运行在 AMD Radeon GPU + ROCm 软件栈上
● 核心推理过程应在 AMD Radeon GPU 上本地执行；核心功能不允许使用远程 API
● 不允许完全依赖闭源 Agent 平台实现核心功能
（2）可选框架
● vLLM / llama.cpp（适配 AMD Radeon GPU）
● Transformers + PyTorch ROCm
● 推荐 Agent 框架：Dify / LangChain / LlamaIndex / AutoGen / CrewAI / OpenWebUI 等，选择你喜欢的任意框架，但须为中立框架。
● 其他符合条件的框架
（3）最低功能要求
作品需至少实现以下 5 项能力中的 2 项（更多能力可获得额外加分）：
● 本地知识检索（RAG）
● 工具调用
● 多步骤任务规划
● 本地多轮记忆
● 清晰的权限控制与隐私保护机制
3. 评审标准（总分：100 分）
（1）AI Agent 功能完整性（60 分）
● 清晰的任务定位与创意应用场景：20 分
● 完整的核心能力，包括任务分解、工具调用、RAG 和记忆管理：20 分
● 流畅的多轮交互体验：20 分
（2）AMD Radeon GPU / ROCm 适配与优化（40 分）
● 核心推理运行在 AMD Radeon GPU 上：20 分
● 针对推理速度的定向优化：20 分
4. 提交要求
（1）项目说明文档
● 应用场景
● Agent 架构图
● 核心能力介绍
● 模型介绍与本地部署方案
● AMD Radeon GPU 推理速度优化说明
（2）项目源代码
● 完整源代码仓库
● README 文件，包含环境配置、启动指南和依赖列表
（3）演示视频
● 建议时长：3–5 分钟
● 展示实际操作流程
● 在 AMD Radeon GPU 上的实际执行表现，从命令行/GUI 到最终结果（流畅度和功能完整性）
（4）补充材料（选择一项）
● PPT / 海报
