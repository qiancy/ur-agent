## 3. CR-01 当前状态（已拍板 / 已冻结）

### 3.1 决策链（已全部 PM 批准）

- **P0-1**：商品无独立 `name` 字段，`product_uid` 即商品业务名/编号；`description` 复用 `resource.content`。
- **P0-2**：非 ecommerce 资金流必须走 `/spaces/current/transactions`，**禁止**复用旧 `/summary`、`/transactions`（后者走 `require_org_context` 含公开 `?ouid=` 兜底）。
- **P1**：`warehouse_count`→`stock_location_count`（与 Seller summary 口径一致）；timeline 多导入排序冻结（`campaign_code ASC, seq ASC`，带 campaign_code/campaign_name）；physical resources 带 `locations` 数组。
- **P2（已修）**：非 physical 的 `amount` 直读 `resource.amount`、`description` 取 `resource.content`；不引用 `virtual_assets` 旧表名。
- **PM 决策**：空间治理全占位；5 个 `/spaces/current/*` 聚合接口；商品 description 复用 content；`zhansan` 演示账号 + 4 空间 membership，密码从 env/.env 读不落源码。
- **AUTH-02 新增决策**：`account.login` 与 `person.puid` 不物理归并；MVP 可同值。登录不解析 `ouid`，注册创建 `account + person`，空间切换只走 `/auth/switch-organization`。

### 3.2 契约要点（T1 实施依据，详见 `CR-01_技术规格补充.md`）

**BE-09（`src/routers/seller.py` 扩展）**
- `GET /seller/products` → `[{product_uid, unit, status, stock_total, stock_location_count, description}]`
- `POST /seller/products` 请求 `{product_uid, unit, description?}`；409 重复；422 缺 product_uid/unit；201 返回列表项结构
- `PATCH /seller/products/{product_uid}` `{status: active|inactive}`；404 未知；不删历史流水

**BE-10（新文件 `src/routers/spaces.py`）**
- `GET /spaces/current/overview|resources|persons|transactions|timeline`
- 全部 `require_strict_org_context`（仅 JWT，禁身份查询参数），清洗 DTO 无 DB ID
- overview：space{ouid,name,type,role} + counts{resources,persons,transactions,recent_events} + funds
- resources：按 type 分组；physical 带 `locations[{warehouse_code,location_path,quantity,unit}]`
- persons：`[{name,puid,role}]`
- transactions：`[{transaction_uid,from_party_name,to_party_name,amount,category,description,created_at}]`，created_at 倒序，limit 默认 20（1–100）
- timeline：全部 active import 事件，`campaign_code ASC, seq ASC`，带 campaign_code/campaign_name；无则 `{events: []}`

**红线（贯穿全部）**：切换必须后端刷 JWT；禁 DB 数字 ID 与 `pid/oid`；非 ecommerce 禁调 `/seller/*` 与旧 `/summary`、`/transactions`；Header AI 只导航不请求；禁提交 node_modules/dist/tsconfig.tsbuildinfo；`puid/ouid` 必须英文安全字符。

## 7. 关键技术事实（省去重新排查）

- 商品 = `resource` 表 `type='physical'` 行：`name`=product_uid、`unit`/`status`/`content` 已有列。
- 库存 = `resource_warehouse.quantity` 汇总；库位数 = `location_path` 去重数。
- `require_strict_org_context`（`src/routers/deps.py`）仅 JWT；`require_org_context` 含 `?ouid=` 兜底，**勿用于新接口**；`require_ecommerce_context` 用于 BE-09。
- 现有 `/resource`、`/personnel` 执行 `SELECT r.*` 泄漏 DB 数字 ID，**不得**用于观察面板。
- 空间包 import：`POST /campaigns/import` + `data/campaigns/*.json`，事件配置原样存 JSONB `payload`，replay 原样返回 → 维度标签作为事件**顶层字段**，读取 `event.payload.info_flow` 等。
- 数据模型：`campaign_import` 表记录导入；无 workspace 表，不新增。
- 测试隔离：持久 DB 用例必须用每轮唯一 puid（`f"{name}_{uuid4().hex[:8]}"`），否则同名 puid 残留导致跨轮失败。
- 远端 DB（1.117.223.223:5435）偶发 `Operation timed out`，属基础设施抖动，单独跑文件可复绿。
