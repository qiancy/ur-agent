## 2. 改动范围

| 文件 | 要求 |
|------|------|
| `src/db/database.py` | 只创建 `person.puid`、`organization.ouid`；删除身份字段迁移；删除数字组织 ID 查询路径 |

## 3. 实现要求

`require_org_context` 只允许两类上下文来源：

1. Bearer JWT，payload 必须含 `puid` 和 `ouid`。
2. 非 ecommerce demo 查询显式传 `?ouid=shu` 等业务字符串。

禁止：

1. 旧查询键。
2. `?ouid=<database numeric key>` 这种数字数据库主键伪装。
3. 返回旧上下文键。
4. 解码旧 token。
5. 自动迁移旧数据库列。
