## 2. 契约冻结（先行确认，T1/T3 并行依据）

以下契约在开工首日冻结，后续仅在不破坏既有测试的前提下微调。

### 2.1 BE-09 Seller 商品 API（契约见规格文档 §2.1；P0-1 已落地：无独立 name 字段）

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/seller/products` | 列表：`product_uid`（即商品名/编号）、`unit`、`status`、`stock_total`、`stock_location_count`、`description` |
| POST | `/seller/products` | 新增：`{product_uid,unit,description?}`，重复 409，成功 201 |
| PATCH | `/seller/products/{product_uid}` | 停用/启用：`{status: active\|inactive}`，未知 404 |

### 2.2 BE-10 空间观察只读 API（契约见规格文档 §2.2；P0-2/P1-2/P1-3 已落地）

| 方法 | 路径 | 说明 |
| :--- | :--- | :--- |
| GET | `/spaces/current/overview` | 空间信息 + counts + funds |
| GET | `/spaces/current/resources` | 资源按 type 分组；physical 带 `locations` 数组（warehouse_code/location_path/quantity/unit） |
| GET | `/spaces/current/persons` | 成员名 + puid + role |
| GET | `/spaces/current/transactions` | **新增（P0-2）**：资金明细，strict JWT，清洗 DTO |
| GET | `/spaces/current/timeline` | 多导入事件，`campaign_code ASC, seq ASC`，带 campaign_code/campaign_name |

全部 `/spaces/current/*` 走 `require_strict_org_context`（仅 JWT），无事件返回空数组。**资金流必须走 spaces namespace（P0-2），前端非 ecommerce 不得调用旧 `/summary`、`/transactions`**。注意：现有 `/resource`、`/personnel` 执行 `SELECT r.*` 会泄漏 DB 数字 ID，**不得**用于观察面板。

### 2.3 前端路由键（T2/T3 对齐）

```
ecommerce:      workbench / products / stock / movements / summary / chat
non-ecommerce:  overview / resources / persons / timeline / flows
```
