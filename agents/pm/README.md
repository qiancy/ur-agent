# 项目管理文档 (_pm)

本目录包含项目管理相关的文档和模板。

## 目录结构

```
_pm/
├── planning/           # 项目规划文档
│   ├── 团队分工.md      # 团队成员分工
│   ├── 进度跟踪.md      # 项目进度跟踪
│   ├── 质量检查.md      # 质量检查标准
│   └── 任务拆分.md      # 任务拆分指南
├── modeling/           # 建模文档
│   └── ai-modeling.md   # AI建模规范
├── templates/          # 模板文件
│   └── AI-建模模板/     # UML建模模板
│       ├── A-定位目标组织/
│       ├── B-生成系统用例图/
│       ├── C-生成分析类图/
│       └── ...
└── README.md           # 本文件
```

## 文档说明

### 项目规划文档 (planning/)
- **团队分工.md**：定义团队成员角色和职责
- **进度跟踪.md**：项目里程碑和进度管理
- **质量检查.md**：代码和文档质量检查标准
- **任务拆分.md**：任务分解和分配指南

### 建模文档 (modeling/)
- **ai-modeling.md**：AI系统建模规范和指南

### 模板文件 (templates/)
- **AI-建模模板/**：各种UML建模模板
  - A类：定位和分析模板
  - B类：用例图生成模板
  - C类：分析类图和序列图模板
  - D类：代码生成和实现模板

## 使用指南

### 对于项目经理
1. 查看 `planning/团队分工.md` 了解团队结构
2. 使用 `planning/进度跟踪.md` 跟踪项目进度
3. 参考 `planning/质量检查.md` 进行质量把控

### 对于系统分析师
1. 查看 `modeling/ai-modeling.md` 了解建模规范
2. 使用 `templates/AI-建模模板/` 中的模板进行建模
3. 生成PlantUML代码和设计文档

### 对于开发人员
1. 查看 `planning/任务拆分.md` 了解任务分配
2. 参考 `templates/AI-建模模板/` 了解系统设计
3. 遵循 `planning/质量检查.md` 进行代码质量检查
