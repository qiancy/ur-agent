# 爆炸法

假设你是建模人员，投资人在你身上绑了炸弹，命令你推销目标系统并且盈利，而且条件很苛刻：（1）几分钟之内推销出去；（2）只能找一个人推销。

假设这个炸弹能感应推销对象的脑电波。推销完毕后，如果炸弹没有感应到推销对象认为这个系统能解决他的问题并且愿意付出相应代价获得系统，炸弹就会爆炸------既然不能盈利，就拿命来填。

这时，为了最大可能地保住自己的性命，你会选择向谁推销？这个人就是目标组织负责人，也就是前面两版所说的"老大"。

很多人可能会第一时间想到向自己的父亲或母亲推销，但是，父母买单只是为了救你的命，并非认为这个系统能解决他的问题，炸弹依然会爆炸！

如果上面的场景还不足以刺激你思考，可以用加强版：

如果投资人在你和你的情敌身上绑了炸弹，命令你们分别按刚才的条件推销目标系统，谁的推销对象对系统感兴趣的脑电波更强，谁就活下来，活下来的人的情敌被炸死。

通过爆炸法初步得到的目标组织负责人，更多是靠直觉得到的，这个结果只是思考的起点，建模人员还需要进一步追问：是什么原因让我选择了他？

以上面的"Uni-Resource Agent"为例，使用"爆炸法"，建模人员凭直觉给出结果"张三（公司员工）"，这时需要进一步追问：

Q：为什么是张三？
A：因为他是公司员工，需要管理公司资产、财务、人员等资源。

Q：就是说，公司员工更像目标组织？公司员工中谁更符合需求？张三所在的公司是最大的吗？比李四所在的公司怎样？
A：......没有李四所在公司大，刚才说错了，是因为我对张三公司比较熟悉。

Q：好，就是说你是先根据熟悉程度来选择的。张三公司是你最熟悉的公司吗？
A：只能说相对于其他公司，我对张三公司比较熟悉，但选择张三的原因应该不是熟悉。

Q：那为什么选张三，他有什么特点？
A：张三需要在公司和家庭两个身份之间切换，管理不同的资源，这样的情况比较适合用我们的系统。

Q：按"在多个身份间切换并管理资源"的条件来看，张三所在的公司是最突出的吗？
A：以我目前掌握的信息看，是的。

Q：假如，李四所在的公司也有类似情况，如果让你再重新思考"爆炸法"的回答，你会不会选择李四？
A：......不会，现在没有实力让他们接受。
