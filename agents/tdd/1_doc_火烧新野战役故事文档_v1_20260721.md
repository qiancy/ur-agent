# 火烧新野战役 - 故事情节与场景文档

## 📜 战役背景

### 时间地点
- **时间**：建安七年（公元202年）秋
- **地点**：新野县周边山林
- **天气**：秋高气爽，干燥少雨

### 战役起因
曹操大军压境，刘备军力薄弱，退守新野。诸葛亮初出茅庐，献上火攻计策，欲以智取胜。
