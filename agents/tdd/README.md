# 测试驱动开发 - 三国角色测试用例

## 项目概述
基于Uni-Resource Agent的多上下文资源管理功能，为三国时期的10个主要角色创建测试用例，验证系统在不同场景下的功能。

## 角色列表
1. 刘备 (Liu Bei) - 仁德之主
2. 关羽 (Guan Yu) - 武艺超群
3. 张飞 (Zhang Fei) - 粗中有细
4. 诸葛亮 (Zhuge Liang) - 智慧军师
5. 曹操 (Cao Cao) - 雄才大略
6. 孙权 (Sun Quan) - 继承基业
7. 吕布 (Lu Bu) - 人中吕布
8. 赵云 (Zhao Yun) - 虎将
9. 周瑜 (Zhou Yu) - 雄才谋士
10. 黄忠 (Huang Zhong) - 老将

## 测试场景设计

### 1. 刘备 - 仁德之主
**场景**: 管理蜀汉军队资源
- 验证库存查询功能
- 测试资源转移操作
- 检查财务记录功能

### 2. 关羽 - 武艺超群
**场景**: 管理武将装备
- 验证装备查询功能
- 测试装备转移
- 检查武将健康提醒

### 3. 张飞 - 粗中有细
**场景**: 管理军需物资
- 验证物资库存
- 测试物资分配
- 检查支出记录

### 4. 诸葛亮 - 智慧军师
**场景**: 知识管理
- 验证知识库搜索
- 测试文档记录
- 检查策略建议

### 5. 曹操 - 雄才大略
**场景**: 多上下文资源管理
- 验证不同身份切换
- 测试数据隔离
- 检查多身份资源分配

### 6. 孙权 - 继承基业
**场景**: 财务管理
- 验证财务记录
- 测试预算管理
- 检查财务摘要

### 7. 吕布 - 人中吕布
**场景**: 管理特殊资源
- 验证特殊资产查询
- 测试资产转移
- 检查状态更新

### 8. 赵云 - 虎将
**场景**: 人员管理
- 验证人员信息
- 测试任务分配
- 检查健康提醒

### 9. 周瑜 - 雄才谋士
**场景**: 战略规划
- 验证战略文档
- 测试知识搜索
- 检查策略实施

### 10. 黄忠 - 老将
**场景**: 资源传承
- 验证资产传承
- 测试资源转移
- 检查历史记录

## 测试框架
- 使用Python unittest
- 基于ouid+puid的上下文隔离测试 (context = {ouid, puid})
- 集成数据库访问测试
- 工具函数验证测试

### Context说明
`context` 是运行时概念，由ouid（组织ID）和puid（人员ID）组成，表示 "person@organization" 上下文

### API参数说明
所有API调用需传递 `ouid` 和 `puid` 参数：
- `ouid`: 组织ID，标识当前操作所属的组织/空间
- `puid`: 人员ID，标识当前操作所属的人员/身份

## 测试目标
1. 验证所有工具函数按预期工作
2. 确保数据隔离和安全性
3. 测试多上下文切换功能
4. 验证资源管理的完整流程
