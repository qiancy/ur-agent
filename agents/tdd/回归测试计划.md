## 🎯 测试目标

基于**火烧新野战役**故事文档，验证系统功能的完整性与正确性：

| 目标 | 描述 |
|------|------|
| ✅ 功能回归 | 验证组织、人员、资源、仓库、交易等核心功能正常工作 |
| ✅ 数据隔离 | 确保战役数据与现有数据完全隔离，不相互影响 |
| ✅ API一致性 | 验证HTTP API接口与数据库操作的一致性 |
| ✅ 业务流程 | 验证"准备→执行→清算"完整业务流程 |
| ✅ 数据准确性 | 验证物资统计、资金流动等数据计算正确 |

## 📊 测试范围

### ✅ 包含的功能模块

| 模块 | 测试点 | 验证方式 |
|------|--------|---------|
| **组织管理** | 创建、查询、查询成员 | HTTP API |
| **人员管理** | 创建、查询、关联组织 | HTTP API |

### 🚫 不包含的功能（排除范围）

| 排除项 | 原因 |
|--------|------|
| AI聊天功能 | 需要外部模型支持，无法本地验证 |
| 文件上传/下载 | 非本次测试重点 |
| 用户认证/授权 | 使用已有测试组织数据 |
| 性能压测 | 单次回归测试不涉及 |
