## 🧪 快速测试

### 获取 JWT Token

```bash
# 基础账号
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"login":"super@system.cn","password":"demo123"}'

# 演示账号
curl -X POST http://localhost:8000/auth/login \
```

## 🔄 重置演示账号密码

如需重置 `zhansan` / `liuming` 为 demo123：

```bash
cd backend
UNIRES_DEMO_PASSWORD=demo123 PYTHONPATH=. python scripts/seed_demo_data.py
UNIRES_DEMO_PASSWORD=demo123 PYTHONPATH=. python scripts/seed_recording_data.py
```

## 📝 注意事项

1. **密码统一**: 所有测试账号密码均为 `demo123`
2. **Salt 随机**: 后端每次写入密码都会生成独立 salt
3. **环境变量**: `UNIRES_DEMO_PASSWORD` 可统一覆盖演示账号 seed 密码
4. **数据隔离**: 测试时请注意 ouid 隔离
