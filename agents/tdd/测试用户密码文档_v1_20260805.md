## 🔧 快速测试命令

### 启动服务

```bash
# 启动后端
cd backend
PYTHONPATH=. uvicorn src.app:app --host 0.0.0.0 --port 8000

# 启动前端（另开终端）
cd frontend
npm run dev -- --host 0.0.0.0 --port 5173
```

### 初始化数据库

```bash
# 清除并初始化
cd backend
DEMO_INIT_PASSWORD=demo123 PYTHONPATH=. python scripts/init_db.py

# 生成演示数据
DEMO_ZHANSAN_PASSWORD=demo123 DEMO_LIUMING_PASSWORD=demo123 PYTHONPATH=. python scripts/seed_demo_data.py
DEMO_LIUMING_PASSWORD=demo123 PYTHONPATH=. python scripts/seed_recording_data.py
```

### 运行测试

```bash
# 后端测试
cd backend
PYTHONPATH=. pytest ../tests/backend -v

# Playwright 测试
PYTHONPATH=. pytest ../tests/playwright -v
```

### 获取 JWT Token

```bash
# 使用 curl 获取 token
curl -X POST http://localhost:8000/login \
  -H "Content-Type: application/json" \
  -d '{"login":"zhansan","password":"demo123"}'

# 响应示例
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

## 📝 注意事项

1. **密码统一**: 所有测试账号密码均为 `demo123`
2. **环境变量**: 密码通过环境变量设置，不硬编码在代码中
3. **数据隔离**: 每个组织/空间使用独立的 ouid，测试时请注意隔离
4. **幂等性**: seed 脚本可重复执行，不会产生重复数据
5. **清理数据**: 测试完成后可使用 `init_db.py` 重新初始化（drop_all=True）
